# EromeDownloader

EromeDownloader - интерактивный Python-загрузчик для альбомов, прямых медиафайлов
и аккаунтов erome.com. Скрипт умеет работать с очередью ссылок, докачивать
прерванные файлы, вести статусы, отслеживать аккаунты и сохранять manifest с
результатами скачивания.

## Возможности

- Скачивание одного URL: альбом, прямой файл или аккаунт.
- Batch-режим для очереди `links/pending.txt`.
- Постоянный список аккаунтов в `links/accs.txt`.
- Отдельный режим проверки аккаунтов без скачивания: новые альбомы добавляются в
  `links/pending.txt`.
- Параллельная загрузка файлов и нескольких альбомов с общим лимитом соединений.
- Автоматическая сортировка очереди: прямые файлы, альбомы, аккаунты.
- Оценка размера альбомов и сортировка альбомов перед скачиванием.
- Докачка через временные `.part` файлы.
- Повторы при таймаутах и временных ошибках сервера.
- Защита от перезаписи файлов с одинаковыми именами.
- Статусы `ready`, `failed`, `banned` для ссылок и аккаунтов.
- Manifest в JSON с URL, путями, размерами, статусами и датами.
- Импорт ссылок на альбомы из экспортированных закладок браузера.

## Требования

- Python 3.10 или новее.
- Зависимости из `requirements.txt`.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

На Linux/macOS активация окружения выглядит так:

```bash
source .venv/bin/activate
```

## Запуск

```bash
python main.py
```

После запуска выберите режим:

1. Скачать одну ссылку: альбом, прямой файл или аккаунт.
2. Скачать все ссылки из `links/pending.txt`.
3. Проверить и скачать новые посты аккаунтов из `links/accs.txt`.
4. Только найти новые посты аккаунтов и добавить их в `links/pending.txt`.

Папки `downloads` и `links` создаются автоматически.

## Файлы очередей и статусов

- `links/pending.txt` - очередь альбомов, прямых файлов и аккаунтов.
- `links/accs.txt` - постоянный список аккаунтов для отслеживания.
- `links/ready.txt` - успешно скачанные ссылки.
- `links/failed.txt` - ссылки, которые не удалось скачать после повторов.
- `links/banned.txt` - недоступные ссылки, например 403/404/410.
- `links/ready_accs.txt` - успешно обработанные аккаунты.
- `links/failed_accs.txt` - аккаунты, которые не удалось обработать.
- `links/banned_accs.txt` - недоступные аккаунты.
- `links/manifest.json` - база результатов скачивания.

В `pending.txt` и `accs.txt` добавляйте по одной ссылке на строку. Пустые строки и
строки с `#` в начале игнорируются.

## Куда сохраняются файлы

Все скачанные файлы сохраняются в `downloads`. Для альбомов создаются отдельные
папки с очищенным названием альбома. Если в альбоме встречаются файлы с
одинаковым именем, скрипт добавляет суффикс и не перезаписывает уже сохраненные
файлы.

## Настройки

Основные параметры лежат в `config.json`. Если файла нет, он создается
автоматически со значениями по умолчанию.

Чаще всего полезны:

- `max_connections` - общий лимит одновременных соединений.
- `max_parallel_albums` - сколько альбомов можно качать одновременно в batch.
- `min_connections_per_parallel_album` - минимальное число соединений на один
  активный альбом.
- `auto_sort_links` - сортировать очередь перед обработкой.
- `sort_albums_by_size` - оценивать размер альбомов и сортировать их.
- `connect_timeout` и `idle_timeout` - сетевые таймауты.
- `max_attempts` и `page_attempts` - число повторных попыток.
- `skip_videos` и `skip_images` - пропускать видео или изображения.
- `manifest_path` - путь к manifest-файлу.

Если в существующем `config.json` нет новых параметров, скрипт берет их из
встроенных значений по умолчанию.

## Импорт ссылок из закладок

1. Экспортируйте закладки браузера в `bookmarks.html`.
2. Положите файл рядом с `main.py`.
3. Запустите:

```bash
python extract_links.py
```

Скрипт найдет ссылки на альбомы erome.com и добавит их в `links/pending.txt`.
