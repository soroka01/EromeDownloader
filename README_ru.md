# EromeDownloader

EromeDownloader — Python-скрипт для скачивания альбомов с erome.com: видео,
изображений и gif. Работает в интерактивном режиме и умеет продолжать скачивание
после обрыва.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

После запуска выберите режим:

1. Скачать одну ссылку: альбом, прямой файл или аккаунт.
2. Скачать все ссылки из `links/pending.txt`.
3. Проверить аккаунты из `links/accs.txt`.
4. Только найти новые посты аккаунтов и добавить их в `links/pending.txt`.

Папка `links` создаётся автоматически. В `links/pending.txt` можно смешивать
ссылки на альбомы, прямые файлы и аккаунты. Для отдельной очереди аккаунтов
используйте `links/accs.txt`, по одной ссылке на строку. Этот файл не очищается
после запуска: держите в нём аккаунты, за которыми хотите следить.

Скрипт не спрашивает технические параметры при каждом запуске. Настройки лежат
в `config.json`: там можно поменять количество соединений, таймауты,
сортировку, пропуск видео/фото и путь к manifest.

## Куда сохраняются файлы

Файлы сохраняются в `downloads`. Для альбомов создаётся отдельная папка с
названием альбома.

## Статусы ссылок

- `links/pending.txt` — ещё не обработанные ссылки.
- `links/accs.txt` — постоянный список аккаунтов для отслеживания.
- `links/ready.txt` — успешно скачанные ссылки.
- `links/failed.txt` — ссылки, которые не удалось скачать после повторов.
- `links/banned.txt` — недоступные ссылки, например 403/404/410.
- `links/ready_accs.txt` — успешно обработанные аккаунты.
- `links/failed_accs.txt` — аккаунты, которые не удалось обработать.
- `links/banned_accs.txt` — недоступные аккаунты.
- `links/manifest.json` — база скачанного: URL, папка, размер, дата и статус.

## Что улучшено в скачивании

- Докачка через временные `.part` файлы.
- Повторные попытки при таймаутах и временных ошибках сервера.
- Увеличенный размер чанка для более быстрой записи.
- Ограничение одновременных соединений, чтобы не перегружать сервер.
- До нескольких альбомов параллельно в batch-режиме: общий лимит соединений не
  увеличивается, он делится между активными альбомами.
- Фото-альбомы скачиваются перед альбомами с видео и сортируются по количеству
  фото от меньшего к большему.
- Для фото-only альбомов используется более широкая параллельность: больше
  альбомов одновременно, но без превышения общего лимита соединений.
- Быстрая первичная сортировка очереди без сетевых запросов: прямые файлы,
  затем альбомы, затем аккаунты. Детальная сортировка альбомов использует
  страницу альбома, которая всё равно нужна для скачивания.
- Защита от перезаписи файлов с одинаковыми именами внутри одного альбома.
- Честный итоговый статус: альбом считается успешным только если файлы реально
  скачались или уже были скачаны.
- Отслеживание аккаунтов: скрипт обходит страницы `?page=N`, собирает все посты
  `/a/...`, пропускает уже обработанные альбомы из `ready.txt`/`banned.txt` и
  оставляет аккаунты в `accs.txt` для следующего запуска.
- Режим без скачивания: можно только проверить аккаунты и добавить новые
  альбомы в `pending.txt`.
- Manifest обновляется после скачивания файлов, альбомов и обработки аккаунтов.

## Импорт ссылок из закладок

1. Экспортируйте закладки браузера в файл `bookmarks.html`.
2. Положите файл рядом со скриптом.
3. Запустите:

```bash
python extract_links.py
```

Скрипт найдёт ссылки на альбомы и сохранит их в `links/pending.txt`.
