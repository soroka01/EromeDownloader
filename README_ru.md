# EromeDownloader V2

EromeDownloader — компактный и мощный Python-скрипт для скачивания альбомов с erome.com (видео, изображения, gif).

## Как использовать?

1. Установите зависимости:

```
pip install -r requirements.txt
```

2. Запустите скрипт:

```
python dump.py
```

3. Следуйте интерактивным инструкциям в консоли:
- Выберите режим (одна ссылка или batch)
- Укажите параметры скачивания
- Для batch-режима добавьте ссылки в файл `links/pending.txt` (по одной на строку)

## Аргументы

- Все параметры вводятся через консольный диалог.
- Ссылки для batch-режима берутся из `links/pending.txt`.

## Куда сохраняются файлы?

Файлы сохраняются в папку `downloads`, внутри которой создаётся папка с названием альбома.

## Статусы ссылок

- `links/pending.txt` — ожидают скачивания
- `links/ready.txt` — успешно скачаны
- `links/failed.txt` — ошибки (можно повторно добавить в pending.txt для повторной попытки)

## Особенности

- Автоматический ретрай при обрыве/зависании
- Динамическая адаптация числа соединений
- Красивый прогресс-бар
- Удобный интерактивный интерфейс
- Сортировка ссылок по весу: сначала скачиваются самые лёгкие (меньший размер файла)
- Для массового импорта ссылок из закладок Chrome используйте скрипт extract_links.py:
	1. Экспортируйте закладки из Chrome в bookmarks.html
	2. Запустите: python extract_links.py
	3. Ссылки автоматически сохранятся в links/pending.txt
